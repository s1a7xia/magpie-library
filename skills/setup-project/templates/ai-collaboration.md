# 项目协作约定

初始化时填写已确认的项目事实，删除不适用段落，不把占位符当作实际配置。

## 分工与生效范围

- Magpie：共享指令、技能及工具配置的来源，不是项目任务执行者。
- Codex：负责用户交给它的方案、实现、受影响前后端的编译检查、相关状态文档与 Git 收尾。
- 普通 dsh 项目：遵循当前用户需求与项目规则，可正常开发并执行已授权操作，不套用微信助手限制。同一任务确定一个主写者，避免并发修改相同文件。
- 微信工作区默认日常聊天，不设会话级启用开关。仅消息开头 `需求：`/`进度：`/`总结：`/`调研：` 或用户明确要求对应项目动作时，才按该工作区 AGENTS.md 加载 REPORTER.md；无前缀问题和附件不向普通项目扩散。

## 项目事实来源

- 仓库与默认分支：<实际远端、分支；没有则明确未配置>
- 当前需求目录：<本次已确认目录；没有则明确未配置>
- 当前状态：维护中的 docs/agents/project-state.md 与可核对 Git 事实。
- 已确认决策与验证证据：维护中的 docs/agents/project-decisions.md 和 verification.md。
- Issue/PR/MR：仅按用户选择及项目实际约定使用，不默认创建或作为需求入口。

只保留项目确实维护的入口；文件缺失、记录过期或事实未知时明确说明。不假定共享文件系统、未提交改动或会话历史。本地提交只有推送后才成为远端可见事实。

## 微信需求与交接（项目使用该入口时保留）

1. 仅“需求：”或明确整理请求触发需求整理；普通问答不建需求。目标项目不明时先询问，草稿不落盘。
2. 使用微信工作区指定的独立需求目录，正文包含目标、范围、验收点、约束、待确认项。不默认进入 Issue。
3. 项目已登记且分支、上游符合保护条件时，微信助手仅通过受控 `publish-wechat-requirement.ps1` 将本条需求与附件写入 `docs/inbox/<需求ID>/`，精确提交并推送该目录；不修改业务源码、项目最终状态与验证记录，不测试，不直接操作其他 Git 路径。
4. 项目未登记、目录不可用、分支或上游不安全、附件不可读时，保留明确标注的本地草稿并报告“未入 Git”，不得伪称已发布。归档不等于自动接单或已经开始开发。
5. Codex 完成实现、受影响前后端的编译检查、相关文档与 Git 收尾；微信助手依据项目文件与 Git 事实汇报，不把提交数量当作验收结论。

## 微信调研简报（项目使用微信调研时保留）

1. `调研：` 使用 Magpie 联网并输出手机可读结论，默认只回答、不写仓库。只有同一请求明确要求归档/形成项目调研简报/给 Codex 续接时，才发布简报。
2. 明确归档且能唯一定位已登记项目后，微信仅通过 `publish-wechat-research.ps1` 写入 `docs/research/inbox/<RES-YYYYMMDD-NNN>/调研简报.md`，按需带 `assets/`，精确提交并推送该目录；不写正式 `docs/research/<stack>-<topic>-<major>.md`，不更新 `INDEX.md`，不改项目状态或业务源码。未点名时只有索引恰好一个项目且问题明显针对它才可使用，多候选先问。
3. 简报必须包含结论、依据与可点击来源、适用边界、待验证项、下一步建议、Codex 续接提示；没来源、联网失败、项目未登记或脚本失败时报告“未入 Git”。
4. Codex 续接先核对简报和原始来源，再决定采纳、补证或晋升为正式 research 记录；简报入库不等于结论已验证。

## 交付与证据

- 默认只检查本次改动涉及的前后端能否编译，不再选择交付档位或重复询问验证授权。前后端均有改动时分别编译；仅改一端时只编译该端，纯文档或不影响编译的配置改动只核对差异。复用项目已有编译/构建命令，跳过测试，不独立运行 lint、类型检查或自动化测试；UI 可见改动另按 `page-acceptance` 走页面验收；已有构建命令内置的编译类型检查可保留。用户明确要求额外检查或暂不编译时按当次要求执行。编译失败或环境缺失时如实报告，不把编译通过等同于功能验收。
- 先核对改动，再更新直接受影响的文档，之后按暂存归属、分支与上游约束提交和推送；存在阻塞时明确说明。
- 区分实现完成、代理实测、用户确认、已提交、已推送与未验证；记录证据对应的版本或提交，不沿用旧版本通过结论。

## 简短交接格式

```text
目标项目与需求目录：
目标 / 范围 / 验收点：
附件与待确认项：
当前状态与证据来源：
需要 Codex 处理的事项：
```

微信进度优先 300 字以内，按“当前 / 进展 / 卡点 / 下一步”回答；普通 dsh 项目按任务需要正常输出。
