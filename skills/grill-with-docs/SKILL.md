读取并遵循 [`grilling`](../grilling/SKILL.md) 与 [`domain-modeling`](../domain-modeling/SKILL.md) 两个技能的 `SKILL.md`，把持续追问和领域文档沉淀作为同一个访谈流程执行。

在 Codex 中也可以显式调用本技能：`$grill-with-docs`。上面两个依赖技能的文件读取属于本技能自身流程，不表示单独启用了 `$grilling` 或 `$domain-modeling`，也不扩大它们各自的授权。
