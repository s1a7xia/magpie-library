# RuoYi-Vue-Plus 页面美化与 UI 规范

本文件是 plus-ui 页面的视觉规范。`frontend-design` 遇到 RuoYi 业务页时按本文件收敛到「既有一致性」；进入独立展示页时按其自身原则自由设计。视觉方向不改变权限、字典、分页、校验等既有行为。

## 组件库红线

业务增删改查页面保留 Element Plus 核心组件（`el-table`、`el-form`、`el-dialog`、`el-pagination`）与若依内置组件（`dict-tag`、`right-toolbar`）。替换为原生 HTML 会丢失排序、校验、键盘与无障碍行为、权限指令和框架后续修复，因此美化只在组件之上做，不做组件替换。

## 界面模式分级

按页面职责选模式，不要在业务页和展示页之间串用：

| 模式 | 页面 | 取向 |
|---|---|---|
| **Operate（业务 CRUD 页 / 列表 / 表单 / 弹窗）** | 增删改查、配置、审批等日常操作页 | 精准与克制。保留 Element Plus 与若依内置组件，重点优化表单对齐、间距呼吸感、`el-tag` 语义化配色（红/橙/绿/灰）与空状态展示 |
| **Experience（登录页 / 工作台首页 / 安全态势大屏 / 独立展示页）** | 一次性进入、要传达品牌或数据的页面 | 视觉表现力放开。可用深色科技主题、高对比度 KPI 指标卡与 ECharts 图表联动 |

Experience 页面不受「组件库红线」限制，可按 `frontend-design` 自由设计；但同样不得绕过既有接口与权限。

## 反廉价感禁令

Operate 页面严禁以下三种「机器装饰感」写法（它们是模板痕迹，不承载任何信息）：

- **侧边粗色条**：卡片或列表项左侧一条粗彩色边框。用 `el-tag` 或状态色块表达状态，而不是靠色条「提神」。
- **渐变字**：正文或标题使用渐变填充。它损害对比度与可读性，是最典型的 AI 生成页特征。
- **无意义毛玻璃**：没有层级或景深理由的模糊/半透明堆叠；它会糊掉文字并拖慢渲染。

这三条是 Operate 模式的禁令，不是技术禁令。Experience 模式下渐变、玻璃面板、彩色描边若有明确目的可以作为刻意选择，但需说明这个目的。

## 业务列表页的发力点

- **层级**：一个页面只设一个视觉焦点，主操作与次操作拉开权重。多数「丑」来自所有元素同等重量，而非装饰不足。
- **间距与密度**：页头、筛选区、表格、分页各自成组，用留白分组，少用边框。沿用产品既有间距刻度。
- **指标卡片**：仅在数据真实支撑时使用，回答一个实际问题；不做装饰性数字，不与 `right-toolbar` 争夺注意力。
- **颜色**：通过主题层调整 `--el-color-primary` 等 CSS 变量，不在组件内散落硬编码色值；`el-tag` 用语义化 `type` 表达状态，同一状态全产品一致。
- **状态设计**：补齐加载、空、错误、无权限四种状态。空状态给出下一步动作，比渐变更能提升完成度。
- **详情排版**：详情用 `el-drawer` 承载时，统一 label/value 节奏；这通常比页头改造更能改善稠密表格的可读性。

## 前端实现约束

- 样式改动限在本页作用域内，不覆盖全局样式影响其他页面，不为单页引入新字体。
- 复用既有 hooks（`openDialog`/`showDialog`）和组件；美化不改变表单重置、编辑回填、失败回滚与加载状态。
- 按钮权限继续走 `v-hasPermi` 或 `checkPermi`；视觉调整不得隐藏或伪造权限控制。
- 字典继续走 `useDict`/`DictTag`；语义配色映射到既有字典值，不另造一套状态词表。
- 表格列显隐、导入导出、树筛选、抽屉等既有交互全部保留。

## 视觉验收

视觉结论以渲染结果为准，不以源码判断。改版后按 `page-acceptance` 走一遍主路径与一个边界（窄视口、长文本或空表格），并保留截图作为证据。仅编译通过不构成美化成败的依据。

交付底线（逐条在渲染页面上核过，不以源码判断）：

- **无意外横向滚动条**：窄视口下没有元素把页面撑出横向滚动；宽表格与长字符串被容器约束，而不是溢出或被截断。
- **按钮文字不折行**：任何宽度与文案下按钮文字保持单行；折行说明容器太紧，不是文案太长。
- **深色模式对比度可读**：正文、次要文字、边框与禁用态在其背景上都清晰可读，不只亮色模式。
- **z-index 无遮挡冲突**：`el-dialog`、`el-select` 下拉、日期选择、`el-tooltip`、`el-drawer` 层级顺序正确，不被其他层遮住或裁切。
