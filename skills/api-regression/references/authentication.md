# 认证与账号生命周期

目标是一次解决认证，然后用独立会话跑业务。不要每轮重新登录，不要猜密码，也不要用全局免密后门。

## 认证优先级

1. 复用用户明确指定的页面登录态：browser storage state、Cookie jar、受保护 Token 文件或专用浏览器 profile。
2. 读取用户指定的本地测试账号文件。
3. 用户临时提供专用测试凭证。
4. 仍无认证时，只请求缺少的那一项；不穷举密码、不抓包、不读任意浏览器 profile、不修改数据库制造登录态。

会话或账号文件必须属于当前目标和角色，放在已忽略或受保护位置。密码、Token、Cookie 和认证头不打印、不提交、不写入报告。

## 缺少密码时的固定提示

没有可用会话，也没有本地账号文件中“已完成首次改密=是”的有效行时，必须在发出登录请求前停止，并给出一条可直接执行的提示。不要反复询问密码，不猜默认密码，不让用户在聊天里粘贴密码。

提示必须包含：

1. 证据文件的**绝对路径**；用户尚未指定时，先提出一个已被 Git 忽略的路径。
2. 只让用户填写哪一行：通常是“引导管理员”行的“当前密码”，并把“已完成首次改密”改为“是”。
3. 明确其他角色账号不需要用户填写，agent 会在获准测试环境创建并回填。
4. 完成后只需回复“已填写”，agent 会重新读取并继续。
5. 当前未发出认证或业务请求。

可直接使用这个句式：

> 缺少可用测试账号凭证。请打开 `<credentials-file>`，在「引导管理员」行填写「当前密码」，确认「已完成首次改密」为「是」并保存；完成后回复“已填写”。其他角色账号不需要你填写，我会在测试环境创建并回填。当前未发起任何认证或业务请求。

如果用户已指定文件，替换为真实绝对路径；如果用户尚未指定，先建议一个项目已忽略的路径，再给同一提示。凭证错误、首次改密未完成或会话失效时，回到这里提示用户更新文件或重新登录，不通过改代码、改数据库或全局免密绕过。

## 本地测试账号文件

使用项目已忽略的 Markdown 或同等可审计格式。只传文件路径，运行时读取密码。推荐结构：

| 维护方 | 用途 | 用户名 | 当前密码 | 已完成首次改密 | 状态 |
|---|---|---|---|---|---|
| 用户 | 引导管理员 | `admin_account` | `local-only-secret` | 是 | 保留 |
| Codex | 申请人 | `e2e_runid_applicant` | `generated-secret` | 是 | 测试中 |

只使用“已完成首次改密=是”且密码非空的行。创建、改密、重置、停用或删除后同步更新。测试结束删除文件。

## 缺少引导管理员密码时

立即停止认证和业务写操作，用一条可直接执行的消息告诉用户去哪里填写，不要只说“请提供账号密码”。若本轮已约定本地账号文件，提示应包含：

- 账号文件的**绝对路径**；
- 表格中的“引导管理员”行；
- 需要填写“当前密码”列；
- 同时确认“已完成首次改密”为“是”；
- 填好后回复即可继续。

提示模板：

> 当前缺少引导管理员密码，测试无法开始。请填写
> `<项目根目录>/.codex/e2e-accounts.local.md` 的“引导管理员”行：
> 在“当前密码”列填入 `admin` 的密码，并把“已完成首次改密”改为“是”。
> 填好后回复“填好了”，我会继续创建测试角色并执行回归。

只请求用户维护引导管理员账密；申请人、审核人等衍生账号由 agent 创建和维护。账号文件为空、密码为空或“已完成首次改密”不是“是”时，均按缺少密码处理，不发起登录请求。

## 只有一个引导管理员

用户只维护一个引导管理员账密时，agent 可在已授权的非生产测试环境创建其余角色：

1. 用管理员独立会话核对身份。
2. 通过应用真实账号管理接口创建唯一 `e2e_<runid>_*` 测试账号，分配场景所需最小角色和部门。
3. 使用应用真实首次改密流程设置随机密码，记录最终密码和完成状态。
4. 为每个账号建立独立会话，核对用户、组织、角色和权限。
5. 测试结束按授权停用或删除衍生账号。

不创建额外超级管理员，不用管理员会话冒充业务角色，不直接修改密码列，不使用 `sys_config` 或全局免密开关。衍生账号失败时保留脱敏证据，不重置整个环境。

## 失败语义

- 401/403、会话过期、首次改密或账号锁定：停止相关写请求，按真实流程重新登录/改密/交接。
- 身份、组织、角色与预期不符：立即停止，不退回管理员继续测。
- 令牌失效最多用同一合法凭证重新登录一次；写请求不自动重放。
- SSO/MFA 或验证码需要人工参与时明确交接，不关闭全局安全策略。
